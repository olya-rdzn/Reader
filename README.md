# Reader

A small, static Reader for course lectures — built for reading parallel texts side by side.
No backend nor tracking. Just open the page and have fun studying :)

## What it does

- **Parallel reading** — Text in different languages in columns next to each other, kept in sync by paragraph.
- **Show / hide languages** — Read one language only or up to 4.
- **Search** — Search option to jump straight to the matching passage.
- **Highlights** — Select text to highlight it. Highlights are saved in your browser only.
- **Reading controls** — Adjust font size, switch light/dark theme.
